exact source
unpacked deploy-artifact.tar.gz from unsafe-artifact.zip (uploaded by PR workflow)

exact sink
tar -xvzf extraction in github-actions/previews/upload-artifacts-to-firebase/action.yml followed by FirebaseExtended/action-hosting-deploy

boundary crossed
A PR-controlled tar archive is extracted into the deployment directory of a privileged workflow_run. An attacker-controlled symlink in the archive is preserved by tar and then traversed by the Firebase CLI (which uses `follow: true` in `glob`), exfiltrating the privileged runner's filesystem to a public Firebase URL.

attacker model
A contributor submitting a PR who can upload a malicious ZIP artifact (containing a crafted tarball with a symlink to `/`) from the unprivileged PR build workflow.

why it is not just CI misuse
The attacker does not need to compromise the privileged workflow directly; they only provide an artifact from an unprivileged PR run. The privileged workflow blindly extracts it and deploys the result, exposing its own secrets (like GITHUB_TOKEN or Firebase service key) to the public internet without the attacker ever running code in the privileged context.

classification: reportable
