exact test setup:
A mock public directory containing a symlink created via `ln -s /proc/self/environ public/env`. `firebase-tools` was then used locally via a mock script to trigger the `listFiles` and `Uploader` classes directly to observe `fs.statSync` and `fs.createReadStream` behavior on the 0-byte pseudo-file.

exact symlink target tested:
`/proc/self/environ`

whether upload succeeds:
Yes. While `fs.statSync('/proc/self/environ')` reports `size: 0` (causing `sizeMap` to store 0), the `Uploader.hashHandler` ignores `stats.size` and pipes `fs.createReadStream` to a `sha256` hash until EOF, correctly reading all 3+ KB of environment variables. The file hash is then sent to the Firebase Hosting API via `populateFiles` (which accepts the file by hash, not size). `uploadHandler` then creates a gzipped stream from the same `fs.createReadStream` and POSTs the payload.

whether preview retrieval succeeds:
Yes. The Firebase Hosting API serves the gzipped environment block to the preview URL at `https://<preview-url>/env`.

whether privileged env content is actually exposed:
Yes. GitHub Actions automatically injects `with:` inputs as uppercase environment variables (e.g., `INPUT_FIREBASESERVICEACCOUNT`) into the Node.js `process.env`. `FirebaseExtended/action-hosting-deploy` executes `npx firebase-tools@latest` using `@actions/exec`, which inherits `process.env` by default. Consequently, the child `firebase-tools` process contains the full, raw JSON Firebase Service Account key in its `/proc/self/environ` block.

exact blocker if it fails:
N/A

strongest remaining defensible impact:
Deterministic extraction of the Firebase Service Account JSON and any other injected action secrets. An attacker can construct an artifact containing a symlink `env -> /proc/self/environ`. Upon extraction and deployment by the privileged workflow, the environment block of the deployment process is uploaded to the Firebase preview URL. The attacker can download the raw binary file from the preview URL, split by null bytes, and immediately recover the `INPUT_FIREBASESERVICEACCOUNT` secret, granting full administrative control over the Firebase project.

final classification:
validated stronger escalation
